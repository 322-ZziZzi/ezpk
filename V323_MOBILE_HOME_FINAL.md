# V323 Mobile Home Final

## Confirmed changes

- Guest mobile flow: brand message → login/sign-up → video → features → migration.
- Member mobile flow: up to two active/upcoming events → 2×2 quick links → expandable full schedule.
- Live events are ordered before upcoming important events.
- Schedule cards support two-line titles and show both server time and the member's local time.
- Loading, empty, and error schedule states are distinct and translated into all eight supported languages.
- Logged-in non-active users no longer see duplicate login/sign-up actions on the home page.
- Member brand area, guest feature cards, and mobile vertical spacing are more compact.
- Mobile menu discovery animation stops after two cycles and respects reduced-motion preferences.

## Responsive rules

- PC quick links: 4×1.
- Mobile quick links: 2×2.
- Mobile schedule: first two cards by default, with an expand/collapse control when more exist.
- Video remains click-to-play.
