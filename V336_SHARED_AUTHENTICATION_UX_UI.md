# V336 Shared Authentication UX/UI

## Unified surfaces

- Login modal and Sign Up page now share the same panel, field, focus, error, spacing, and responsive visual language.
- Login remains the gold action and Sign Up is the deep-blue action.
- PC header and mobile drawer Sign Up controls now use the same blue action color.
- Eight-language labels remain responsive and may wrap without clipping.

## Login modal

- Added a translated supporting description in all eight languages.
- Replaced the legacy cyan-purple submit treatment with a restrained gold Login action.
- Changed the Sign Up link into a full-width blue action.
- Mobile uses a scroll-safe near-full-width card so the software keyboard does not trap the form.

## Sign Up page

- Replaced the legacy cyan-purple submit treatment with the confirmed deep-blue Sign Up action.
- Changed the existing-account Login control into a full-width gold action.
- Standardized fields to 48px height and 10px radius with a restrained gold focus state.
- Existing registration API, validation mapping, password toggles, and post-registration profile redirect are unchanged.
