# V325 Compact Event Command Card Final

## Final behavior

- Logged-in home order on PC and mobile: Quick Links → Event Schedule → Brand → Video.
- Quick Links remain PC 4×1 and mobile 2×2.
- Event Schedule shows two events by default on every viewport.
- PC schedule uses two columns; mobile uses one column.
- Three or more events enable translated expand/collapse controls.
- Live events sort first, then important events, then the earliest start time.
- Cards show status, important badge, title, server time (ST), and concise remaining time only.
- Local/member time and large second-by-second countdowns are removed.
- Empty, loading, and API-error schedule states stay hidden on the home page.
- Live cards use a restrained green pulse; important cards use gold accents.
- New schedule labels are available in all eight supported languages with RTL support.
