EZPK Cloudflare D1 Migration Guide (무료 플랜)

[프로젝트 구조]
- worker.js
- wrangler.jsonc
- package.json
- migrations/
  - 0001_core_tables.sql
  - 0002_system_tables_and_defaults.sql
  - 0003_triggers.sql
  - 0004_indexes.sql
  - 0005_views.sql

[현재 기존 D1을 그대로 Migration 관리로 전환하는 방법]
기존 테이블이 이미 설치되어 있어도 모든 CREATE 문은 IF NOT EXISTS,
기본 설정은 INSERT OR IGNORE로 작성되어 있으므로 초기 Migration을 적용할 수 있습니다.

1. PC에 Node.js 설치
2. 프로젝트 폴더에서 npm install
3. npx wrangler login
4. 현재 원격 DB의 적용 예정 목록 확인
   npm run migrate:list
5. 원격 D1에 Migration 적용
   npm run migrate:remote
6. 이후 일반 배포
   npm run deploy

[Migration과 배포를 한 번에 실행]
npm run deploy:with-migrations

Cloudflare Git 자동 배포 명령을 자동 Migration 방식으로 바꾸려면:
npm run deploy:with-migrations

처음에는 안전하게 아래처럼 분리 운영하는 것을 권장합니다.
- DB 변경 시: npm run migrate:remote
- 사이트 배포 시: npm run deploy

[새 Migration 생성]
예:
npm run migration:create -- add_member_profile_image

생성된 새 SQL 파일에 변경 SQL을 작성한 후:
npm run migrate:remote

[로컬 테스트]
npm run migrate:local
npm run dev

[중요]
- Wrangler 설정의 database_id는 현재 ezpk-members D1 UUID와 일치해야 합니다.
- ADMIN_SETUP_KEY와 PASSWORD_PEPPER는 GitHub에 올리지 않습니다.
- Cloudflare Secret에 등록한 PASSWORD_PEPPER는 회원 생성 후 변경하면 기존 비밀번호 검증이 불가능합니다.
- 이미 적용된 Migration 파일의 내용을 수정하지 말고, 새 Migration 파일을 추가하세요.
